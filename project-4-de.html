Produktkatalog-Anwendung

Eine Full-Stack-Webanwendung, die entwickelt wurde, um einen Produktkatalog effizient mit einer modernen, reaktionsschnellen Benutzeroberfläche anzuzeigen und zu verwalten. Die Anwendung bietet Benutzern die Möglichkeit, Produkte nach Kategorien und Preis zu durchsuchen, zu filtern und zu sortieren.

Die Produktdetails umfassen Name, Beschreibung, Bild und Preis, alles dargestellt in einem sauberen und strukturierten Layout, das das Einkaufserlebnis verbessert.

  • Funktionen:
    • Anzeige einer breiten Palette von Produkten in einem responsiven Grid-Layout
    • Filtern von Produkten nach Kategorien zur schnellen Navigation
    • Dynamische Suche nach Produkten nach Namen
    • Sortieren von Produkten basierend auf dem Preis (aufsteigend/absteigend)
    • Backend unterstützt Data Seeding für Kategorien und Produkte
    • Vollständig lokalisierte Benutzeroberfläche (Arabisch) für regionale Barrierefreiheit
  • Verwendete Technologien:
    • Frontend: React.js, HTML, CSS
    • Backend: Spring Boot (Java)
    • Datenbank: PostgreSQL
    • API: REST API für die Client-Server-Kommunikation
