KI-gestützte Analyse-Plattform

Ein modernes Tool zur automatischen Analyse von Google-Bewertungen. Die Plattform importiert Bewertungen, analysiert diese mittels KI und visualisiert die Ergebnisse in einem übersichtlichen, modernen Dashboard.

  • Das Problem: Viele Unternehmen kämpfen mit:
    • Unübersichtlichen Google-Bewertungen
    • Fehlender automatischer Analyse oder Zusammenfassung
    • Keinem Überblick über Trends & kritische Punkte
    • Keiner Erkennung von potenziellen Fake-Bewertungen
  • Die Lösung:
    • Automatischer Import von Bewertungen
    • KI-Zusammenfassung + Verbesserungsvorschläge
    • Schlüsselwort-Analyse (positiv/negativ)
    • Fake-Bewertungserkennung via OpenAI
    • Trend-Graphen & Kategorie-Analyse
Technologien
  • Frontend: React, TailwindCSS, Vite, Framer Motion
  • Backend: Spring Boot, OpenAI API, SerpAPI
  • Datenbank: PostgreSQL
  • Tools: IntelliJ, GitHub, Postman
