KI-gestützte Arztbesuch-Vorbereitung

Eine Fullstack-Webanwendung, die Patient:innen hilft, sich strukturiert auf Arztbesuche vorzubereiten. Die App unterstützt Nutzer dabei, relevante Beobachtungen festzuhalten, Gespräche gezielter zu führen und Nachsorgehinweise besser einzuordnen.

  • Ziel: Strukturierte Vorbereitung für bessere Arztgespräche.

    Viele Patienten fühlen sich unsicher oder vergessen wichtige Punkte. Der Advisor hilft, Symptome und Fragen vorab zu klären.
  • Hauptfunktionen:
    • 🩺 Auswahl von Fachrichtung & Besuchsgrund
    • 📝 KI-gestützte Checklisten (Vor, Während, Nach dem Termin)
    • 🤖 Kontextbezogene Hinweise via Spring AI & OpenAI
    • 🛡️ Datenschutzfreundlich & ohne medizinische Diagnose
    • 🖥️ Modernes React Frontend mit Ant Design
  • Technischer Fokus:
    • Spring Boot 3 & Java 21 Backend
    • Integration von Spring AI zur Prompt-Steuerung
    • Saubere REST-Architektur
    • Fullstack mit React & TypeScript
Technologien
  • Backend: Java 21, Spring Boot 3, Spring AI, OpenAI API
  • Frontend: React, TypeScript, Ant Design
  • Tools: Git, GitHub, Maven

Projektziel:
Zeigen, wie KI genutzt werden kann, um Patienten im Alltag echten Mehrwert zu bieten – verantwortungsvoll und unterstützend.

Hinweis: Diese Anwendung dient ausschließlich Informationszwecken. Sie ersetzt keine ärztliche Diagnose, Beratung oder Behandlung. Bei gesundheitlichen Fragen sollte immer medizinisches Fachpersonal konsultiert werden.
