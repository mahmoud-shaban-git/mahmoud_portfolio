Benutzerverwaltungs-Anwendung

Eine Webanwendung, die entwickelt wurde, um Benutzerinformationen effizient über eine saubere und reaktionsschnelle Benutzeroberfläche zu verwalten. Die App bietet Kernfunktionen zum Hinzufügen, Anzeigen, Bearbeiten und Löschen von Benutzerdatensätzen. Benutzer können Details wie Name, Benutzername und E-Mail in einem strukturierte Tabellenformat sehen, was die Datenhandhabung einfach und organisiert macht.

Funktionen:
  • - Neue Benutzer mit einem einfachen Formular hinzufügen
  • - Alle Benutzer in einer dynamischen Tabelle anzeigen
  • - Benutzerinformationen bearbeiten und löschen
  • - Responsives Design für ein reibungsloses Benutzererlebnis
Verwendete Technologien:
  • Frontend: React.js / HTML / CSS / Bootstrap
  • Backend: Spring Boot (Java)
  • Datenbank: PostgreSQL
  • API: REST API für die Client-Server-Kommunikation
