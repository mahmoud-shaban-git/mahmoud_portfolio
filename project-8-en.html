AI-Powered Medical Visit Preparation

A fullstack web application that helps patients prepare for doctor visits in a structured way. The app assists users in recording relevant observations, conducting conversations more purposefully, and better understanding follow-up care instructions.

  • Goal: Structured preparation for better doctor consultations.

    Many patients feel unsure or forget important points. The Advisor helps clarify symptoms and questions beforehand.
  • Main Features:
    • 🩺 Selection of medical specialty & reason for visit
    • 📝 AI-generated checklists (Before, During, After appointment)
    • 🤖 Context-aware advice via Spring AI & OpenAI
    • 🛡️ Privacy-focused & no medical diagnosis
    • 🖥️ Modern React Frontend with Ant Design
  • Technical Focus:
    • Spring Boot 3 & Java 21 Backend
    • Integration of Spring AI for prompt engineering
    • Clean REST Architecture
    • Fullstack with React & TypeScript
Technologies
  • Backend: Java 21, Spring Boot 3, Spring AI, OpenAI API
  • Frontend: React, TypeScript, Ant Design
  • Tools: Git, GitHub, Maven

Project Goal:
Demonstrate how AI can be used to provide real value to patients in everyday life – responsibly and supportively.

Disclaimer: This application is for informational purposes only. It does not replace medical diagnosis, consultation, or treatment. For health-related questions, always consult qualified medical professionals.
